# Dev Stack
Dev Stack is a React-based web application that helps developers explore different development technologies and build their ideal technology stack.
## Project Description
The application displays technology cards containing information such as name, category, description, difficulty level, rating, and badge. Users can add technologies to their personal stack, remove individual technologies, or clear the entire stack.
## Technologies Used
- React
- JavaScript (ES6+)
- CSS
- Vite
- JSON
- React-Toastify
## React Questions and Answers

### 1. What is JSX?
JSX stands for JavaScript XML. It allows us to write HTML-like syntax inside JavaScript when building React user interfaces.
### 2. What is the difference between Props and State?
Props are used to pass data from a parent component to a child component. State stores data that a component manages and can update over time.
### 3. What is the useState Hook?
The useState Hook allows a functional component to store and update state. When the state changes, React can re-render the component.
### 4. What is the useEffect Hook?
The useEffect Hook is used to perform side effects in a component, such as fetching data from a JSON file when the component loads.
### 5. Why is the key prop important in React?
The key prop helps React identify individual items in a list and track changes when items are added, removed, or updated.
### 6. What is Conditional Rendering?
Conditional rendering means displaying different content based on a condition. For example, Dev Stack displays a loading message while technology data is being fetched.
### 7. How do components communicate in React?
A parent component can pass data and callback functions to child components through props. A child component can call a callback function to request an action from its parent.
